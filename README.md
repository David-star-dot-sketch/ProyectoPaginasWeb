# ProyectoPaginasWeb
Repositorio del proyecto de paginas web

Este proyecto es una réplica del sitio web de **Fresha**, un salón de belleza moderno que ofrece servicios como cortes, tintes, faciales y más.

## Tecnologías utilizadas
- HTML
- CSS
- Bootstrap 5

## Descripción
Se creó una página responsiva que muestra:
- Barra de navegación
- Sección de agenda
- Promociones
- Servicios
- Testimonios
- Estilos visuales adaptados a la marca original
